# Дизайнерские инструменты

Выбирай модуль по реальному источнику, не по доступности любимого tool.

| Источник | Вход |
| --- | --- |
| Figma | [Figma AGENTS](figma/AGENTS.md) |
| Penpot cloud/self-hosted | [Penpot AGENTS](penpot/AGENTS.md) |
| Предоставленный export | [Общие ресурсы](../docs/resources.md), provider local |

Модули описывают использование доступных инструментов, а не поставляют MCP/API-клиент. Общие правила — в docs, endpoint-справочники не копируются. Неиспользуемые модули не читаются. Сейчас installer с удалением модулей не реализован.
