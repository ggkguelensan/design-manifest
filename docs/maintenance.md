# Сопровождение

При изменении найди владельца нормы и потребителей. Устрани смысловые дубли, сохрани условия и исключения, обнови schemas/skills/examples одним изменением. README даёт обзор человеку; AGENTS.md маршрутизирует агента; docs содержат нормы; stack описывает инструменты; skills — процедуры.

Сначала читай ветку задачи, а не все provider-модули. Общие требования не копируются в Figma и Penpot. API-детали сверяются с официальной документацией используемой версии; инструкции tools могут требовать отдельного установленного skill.

Проверь ссылки, schemas и negative cases валидатора. Формальная валидация не означает live-проверку API или правильность визуального решения. В результате укажи выполненные проверки и ограничения.

Рабочие данные игнорируются. Новая несовместимая схема получает новую schema_version; версия пакета и версия формата — разные значения. История живёт в Git, не в нормативных описаниях текущей модели. Разрешение публикации общей базы не распространяется на пользовательские макеты и evidence.
