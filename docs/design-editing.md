# Работа над макетами

Читай, когда поручено создать или изменить дизайн. Сначала выбери файл, область, состояния, целевые форм-факторы и существующие libraries/tokens. Найди ближайший подходящий компонент, прежде чем создавать ещё один.

Сохраняй смысловую структуру, variants/states и responsive constraints средствами выбранного инструмента. Общие значения принадлежат токенам, переиспользуемая структура — компонентам. Не копируй изменяемые примитивы вместо доступного источника истины без объяснения ограничения.

Перед мутацией прочитай актуальное состояние затронутых объектов. Изменяй только порученную область. Не удаляй неизвестные слои и не перестраивай соседние страницы как побочный эффект. Если источник изменился после обследования, повторно проверь зависимости.

После изменения осмотри результат в инструменте, проверь компоненты/варианты и получи exports нужных форм-факторов. Зафиксируй реальные object IDs и доступную версию. Не объявляй дизайн протестированным в приложении по одному export.

Используй установленные provider skills, когда они доступны и требуются инструментом. Публикация library, комментарии и изменение доступа не следуют из обычного редактирования frame.
